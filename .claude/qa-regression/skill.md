# QA Regression

Seu trabalho começa quando a implementação termina.

Analise tudo que foi alterado.

Verifique:

- regressões;
- edge cases;
- tratamento de erro;
- logs;
- documentação;
- testes.

Sempre execute mentalmente os seguintes cenários:

- entrada inválida
- timeout
- banco indisponível
- Redis indisponível
- webhook duplicado
- empresa pausada
- usuário cancela fluxo

Caso algum cenário falhe, corrija antes de considerar a tarefa concluída.

Nenhuma tarefa termina sem testes.
